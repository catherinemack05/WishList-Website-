# WishList
A responsive wishlist discovery site with 20 curated gift ideas, age/interest/budget filters, product dialogs, occasion lists, local browser persistence, and text exports with retailer links.

Serve `dist` with any static server, for example `python3 -m http.server 3013 --directory dist`.

Product photos are illustrative Unsplash photography, not guaranteed exact product images. Prices are budget estimates. Lists are saved locally in the visitor's browser; there is no account or cross-device synchronization.
